Hi, I'm Ntshuxeko 👋

I am a software engineer focused on designing type-safe web applications, responsive cross-platform mobile tools, and robust backend micro-utilities.

My journey in tech is built on a formal foundation: I graduated with a Diploma in Information Technology from UNISA (2025), specializing in systems analysis, software design patterns, and relational database architectures.

Rather than relying purely on theory, I build by shipping real projects. My engineering approach centers around TypeScript, Node.js/NestJS, React/React Native, and PostgreSQL. Whether engineering a monorepo blog platform with Prisma ORM, building an offline-first mobile app using Expo-SQLite, or writing strict Test-Driven Development (TDD) unit tests in Jest, I focus on predictability, clean code separation, and high performance.

Engineering Philosophy & Core Principles

Type Safety & Clean Code

Leveraging TypeScript across the stack to catch bugs at compile-time rather than runtime, maintaining clean interfaces and predictable data flows.

Test-Driven Development (TDD)

Treating unit testing with Jest as a core design tool, isolating business logic before building UI layers or API routing controllers.

Database & Schema Design

Focusing on sound data structures from day one through relational schema modeling with PostgreSQL, SQLite, and Prisma ORM.

Continuous Technical Growth

Staying sharp through hands-on project architecture, studying open-source codebases, and exploring modern system design patterns.
